## Team Scope v1.2.1

업데이트 후 **예전 화면이 그대로 남는 문제**를 고친 수정 릴리스입니다. 데이터 형식 변경이 없어 v1.2.0에서 그대로 업데이트할 수 있습니다.

### 🐛 수정

- **업데이트했는데 화면·기능이 예전 그대로이던 문제**
  - 원인: `app.js`·`style.css` 주소가 버전과 관계없이 같아서, 브라우저가 예전 파일을 계속 사용했습니다. 서버는 새 버전인데 화면은 예전 코드로 동작했습니다.
  - CSS·JS 주소에 버전을 붙였습니다 (`app.js?v=1.2.1`). 버전이 바뀌면 브라우저가 자동으로 새 파일을 받습니다.
  - Apache `.htaccess`에서 화면 파일(html·js·css)을 매번 서버에 확인하도록 했습니다 (`Cache-Control: no-cache`).
  - 테스트가 화면 파일의 버전과 앱 버전이 같은지 검사합니다.

### 📘 문서

- 운영 문서의 nginx·Apache 예시 설정에 같은 캐시 설정을 추가했습니다.
- 장애 표에 "업데이트했는데 예전 그대로"일 때 확인 방법을 추가했습니다.
  - 헤더의 버전 표시가 예전 번호면 서버 쪽 문제(웹 루트 경로, PHP opcache)
  - 새 번호인데 화면이 예전이면 브라우저 캐시

### ⬆️ 업데이트 방법

```bash
git pull origin main          # 또는 v1.2.1 태그 체크아웃
sudo systemctl reload php8.3-fpm   # Apache는 sudo systemctl reload apache2
```

- **v1.1.0 이하에서 올라오는 경우**에는 [v1.2.0 릴리스](https://github.com/resious71/Team_N_Scope/releases/tag/v1.2.0)의 마이그레이션 안내(`php tools/migrate.php --dry-run` → `php tools/migrate.php`)를 먼저 따르세요.
- **nginx**는 `.htaccess`를 읽지 않으므로 서버 설정에 다음 한 줄을 넣고 다시 읽어 들이세요.
  ```nginx
  location ~* \.(?:html|js|css)$ { expires -1; }
  ```
- 이번 업데이트부터는 사용자가 Ctrl+F5를 하지 않아도 새 화면을 받습니다.
