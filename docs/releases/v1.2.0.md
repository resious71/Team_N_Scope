## Team Scope v1.2.0

관계 평가 구조와 열람 권한을 바꾼 릴리스입니다. 기존 데이터는 **자동으로 변환**되며, 새 마이그레이션 도구로 백업·보고와 함께 변환할 수 있습니다.

### 🔐 관계 열람 권한 변경

- **모든 관계는 관리자만** 봅니다.
- **팀장·부서장·부서원**은 본인이 등록한 평가만 봅니다.
  - 다른 사람이 입력한 평가는 본인이 포함된 관계라도 보이지 않습니다 (서버에서 내려보내지 않음).
  - 본인이 당사자인 관계만 추가·수정·삭제합니다. 상대로 고를 수 있는 범위는 팀장은 팀 전체, 부서장·부서원은 자기 부서입니다.
- 팀장·부서장의 **점수·순위는 지금처럼 전체 관계 기준**으로 보입니다.
- **부서원 화면의 관계도**에는 다른 사람 이름의 **마지막 한 글자만** 표시합니다 (노드 이름·툴팁·PNG/PDF 저장, 본인 이름은 그대로).

### ✨ 평가자별 평가

- 한 쌍(A↔B)에 **A의 평가, B의 평가, 관리자 평가**를 따로 저장합니다. 관리자 평가는 관리자만 입력합니다.
- 점수와 관리자 관계도는 쌍의 평가 중 **낮은 값** 기준입니다.
- 관리자 탭 관계 목록에 평가자별 평가를, 변경 이력에 누구의 평가가 어떻게 바뀌었는지를 표시합니다.
- 삭제: 당사자는 본인 평가만, 관리자는 쌍의 평가 전체를 지웁니다.
- 팀 내보내기 파일에 평가자별 평가(`evals`)가 포함됩니다.
- 팀 설정의 "부서원 관계도 공개 범위"는 제거했습니다.

### 🧰 마이그레이션 도구 `tools/migrate.php`

```bash
php tools/migrate.php --dry-run                       # 바뀔 내용만 보고
php tools/migrate.php                                 # 변환 (전에 data 전체 자동 백업)
php tools/migrate.php --from <예전 data 폴더 | 백업.tar.gz> [--force]   # 예전 서버 데이터를 옮기며 변환
```

- 계정: 빠진 필드 보완, 로그인 ID 소문자화, 깨진·중복 계정 보고 (비밀번호는 그대로)
- 팀·부서·인력: 기본값 보완, 예전 10색 → 파스텔 16색, 중복 팀장/부서장 정리
- 관계: 평가자별 평가로 변환, 없는 인력을 가리키는 관계 제거
- 여러 번 실행해도 결과가 같고, 실행 기록은 `data/migrations.json`에 남습니다.

### ⬆️ 업데이트 방법

```bash
git pull origin main          # 또는 v1.2.0 태그 체크아웃
php tools/migrate.php --dry-run
php tools/migrate.php
```

- 도구를 실행하지 않아도 서버가 처음 읽을 때 같은 규칙으로 자동 변환합니다 (백업·보고 없음).
- 기존 관계는 **마지막 수정자가 당사자면 그 사람의 평가, 아니면 관리자 평가**가 됩니다. 관리자나 예시 데이터로 만든 관계는 관리자 화면에만 보이므로, 각자 본인 평가를 다시 입력하면 됩니다.
- 1.1.0 이하에서 내보낸 팀 파일은 각 관계를 관리자 평가로 가져옵니다.
- **개인정보 안내문이 바뀌어** 모든 사용자가 다음 로그인 때 다시 동의해야 합니다.
