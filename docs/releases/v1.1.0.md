## Team Scope v1.1.0

관리자 편의 기능과 화면 개선 릴리스입니다. **데이터 형식 변경이 없어** v1.0.0에서 그대로 업데이트할 수 있습니다.

### ✨ 새 기능

- **비밀번호 직접 지정**: 부서원을 추가할 때 관리자가 비밀번호를 정할 수 있습니다.
  - 비워 두면 기존처럼 임시 비밀번호가 발급됩니다.
  - "첫 로그인 때 비밀번호 변경 요구"는 선택할 수 있습니다.
- **부서원 목록에서 비밀번호 변경**: 각 행의 버튼으로 모든 인력의 비밀번호를 바꿉니다.
  - 계정이 없는 사람은 로그인 ID를 입력하면 계정을 만들고 비밀번호를 지정합니다.
  - 로그인 잠금도 함께 해제됩니다.
- **부서원 목록에서 부서 바로 변경**: 부서 칸이 드롭다운이 되었습니다.
  - 부서장을 옮기면 공석 경고가 나옵니다.
  - 이미 부서장이 있는 부서로 부서장을 옮기는 것은 거부됩니다.
- **관계 관리 상태 필터**: 관리자 탭과 관계도 화면의 관계 관리 카드에서 이름과 함께 상태(사적/공적/사회적)로 거를 수 있습니다.

### 🎨 화면

- **차분한 라이트 테마**: 순백을 쓰지 않아 모니터로 오래 봐도 눈이 덜 피로합니다.
  - 바탕·카드·입력칸은 회청색 계열입니다.
  - 헤더와 탭은 짙은 슬레이트색입니다.
  - 강조색과 버튼은 채도를 낮춘 파랑입니다.
- **부서 색상 파스텔 16색**
  - 이웃한 부서끼리 잘 구분되도록 색 순서를 섞어 배치했습니다.
  - 관계도 노드에 같은 계열의 진한 테두리를 넣었습니다.
- **카드 높이 통일**: 부서 관리 탭(부서 추가·수정), 부서원 관리 탭(부서원 추가·선택한 부서원·일괄 등록)

### ⬆️ 업데이트 방법

```bash
git pull origin main   # 또는 v1.1.0 태그 체크아웃
```

- 별도 마이그레이션 작업은 필요 없습니다.
- v1.0.0의 10색을 쓰던 부서는 처음 읽을 때 새 색상표에서 겹치지 않는 색으로 **자동 재배정**됩니다. 그래서 기존 부서의 색이 바뀝니다.
  - 예전에 내보낸 팀 JSON 파일을 가져올 때도 같은 방식으로 처리됩니다.
- 개인정보 안내문은 바뀌지 않아 다시 동의할 필요가 없습니다.

### 🔐 참고

- 관리자가 정한 비밀번호는 관리자도 알고 있게 됩니다. 필요하면 "첫 로그인 때 비밀번호 변경 요구"를 켜서 본인이 다시 정하게 하세요.
- 새 API `account_set_password`는 관리자 전용입니다 (부서원이 호출하면 403).
