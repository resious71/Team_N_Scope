## Team Scope v1.0.0 — 첫 정식 릴리스

팀 내 인간관계를 D3.js 원형 관계도로 시각화하는 다중 사용자 웹 애플리케이션의 첫 정식 버전입니다. DB 없이 **PHP 8.1+ 와 JSON 파일**만으로 동작합니다.

### ✨ 주요 기능

**관계도**
- 균등 배치 원형 관계도: 정반대에 있는 두 사람의 관계만 직선, 나머지는 곡선
- 상태별 색과 선 스타일(실선·점선·파선), 상태별 표시 필터, 사람 검색 강조, 해상도 슬라이더
- 범위 필터(팀 / 부서 / 부서원), 관계도 PNG·PDF 저장, 30초 자동 갱신

**역할과 직급**

| | 볼 수 있는 범위 | 관리할 수 있는 관계 | 점수·순위 |
|---|---|---|---|
| 관리자 | 모든 팀 | 팀 전체 | 팀 전체 |
| 팀장 | 팀 전체 | 팀 전체 | 팀 전체 |
| 부서장 | 자기 부서 | 자기 부서원 사이 | 자기 부서 |
| 부서원 | 자기 부서 | 같은 부서원과의 본인 관계 | 본인 점수만 |

- 모든 권한은 서버에서 검사하고, 보이면 안 되는 데이터는 처음부터 내려보내지 않습니다.
- 부서원에게는 내 관계를 마지막으로 바꾼 사람을 이름 대신 역할로 보여 줍니다.

**관리자 기능**
- 팀(인원 한도, 공개 범위)·부서·부서원(직급, 계정) 관리, 팀 JSON 내보내기·가져오기
- CSV 일괄 등록: 엑셀 CSV 지원, 한 행이라도 오류가 있으면 전체 등록 안 함
- 관계 변경 이력, 월별 점수 추이 차트
- 활동 로그 검색과 페이지 넘김, 관리자 계정 웹 관리, 팀장·부서장 공석 경고

**보안·운영**
- 세션 로그인과 CSRF 토큰
- 매 요청마다 계정 상태 재확인: 비활성화하면 기존 세션도 즉시 차단
- `로그인 ID + IP` 기준 로그인 잠금, 개인정보 안내 동의(개정 시 재동의)
- 보안 헤더와 CSP, D3는 외부 CDN 없이 저장소에 포함
- 동시 사용에 안전한 저장: 잠금 파일 + 원자적 파일 교체
- 관리자 CLI, 매일 백업 스크립트(14일 보관)
- 배포 방식 두 가지: 프로젝트 폴더(`index.php` + `.htaccess`) 또는 `public/` document root

### 🚀 시작하기

```bash
git clone https://github.com/resious71/Team_N_Scope.git
cd Team_N_Scope
php -S localhost:8000 router.php
```

<http://localhost:8000> 에 접속해 기본 관리자 `admin` / `admin` 으로 로그인합니다. 관리자 → 팀 관리에서 "샘플 데이터 생성"으로 예시 팀을 만들 수 있습니다.

### ⚠️ 배포 전 확인

- 기본 관리자 `admin` / `admin`의 비밀번호를 **배포 직후 변경**하세요.
- 운영 환경은 **HTTPS 필수**입니다.
- 프로젝트 폴더 방식이라면 `…/data/users.json`이 404 또는 403인지 확인하세요 (Apache `AllowOverride` 필요).
- 관계 평가는 민감한 개인정보입니다. 조직의 개인정보·인사 규정을 검토하세요.
