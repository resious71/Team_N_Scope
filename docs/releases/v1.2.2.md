## Team Scope v1.2.2

팀장·부서장의 **관계 열람 범위를 넓힌** 릴리스입니다. 데이터 형식 변경이 없어 v1.2.x에서 그대로 업데이트할 수 있습니다.

### 🔐 관계 열람 권한 변경

v1.2.0의 "모든 관계는 관리자만"을 바꿔, 팀장·부서장이 직급 범위 안의 관계를 모두 봅니다.

| | 관계도 | 볼 수 있는 관계 | 추가·수정·삭제 |
|---|---|---|---|
| 관리자 | 모든 팀 | 모든 관계 + 평가자별 평가 | 모든 관계 (관리자 평가) |
| **팀장** | **모든 부서** | **팀 전체 모든 관계** | 본인이 당사자인 관계만 |
| **부서장** | **자기 부서** | **자기 부서원 사이 모든 관계** | 본인이 당사자인 관계만 |
| 부서원 | 자기 부서 | 본인이 등록한 평가만 (이름은 마지막 한 글자) | 본인 관계만 |

- 팀장·부서장은 남의 관계를 **보기만** 합니다. 관리자 평가 입력은 그대로 관리자만 합니다.
- 남의 관계는 쌍의 평가 중 **낮은 값**으로 표시합니다.
- 쌍마다 누가 어떤 평가를 했는지(A의 평가·B의 평가·관리자 평가)는 관리자만 봅니다.
- 관계 관리 카드의 목록은 본인이 입력한 평가만 표시합니다.
- 부서원 화면은 바뀌지 않았습니다.

### ⬆️ 업데이트 방법

```bash
git pull origin main          # 또는 v1.2.2 태그 체크아웃
sudo systemctl reload php8.3-fpm   # Apache는 sudo systemctl reload apache2
```

- **개인정보 안내문이 바뀌어** 모든 사용자가 다음 로그인 때 다시 동의해야 합니다.
- 화면 파일 주소가 `?v=1.2.2`로 바뀌어 브라우저가 새 화면을 자동으로 받습니다.
- **v1.1.0 이하에서 올라오는 경우**에는 [v1.2.0 릴리스](https://github.com/resious71/Team_N_Scope/releases/tag/v1.2.0)의 마이그레이션 안내(`php tools/migrate.php --dry-run` → `php tools/migrate.php`)를 먼저 따르세요.
